# armox

## ساخت اپ اندروید (WebView)

پوشه‌ی `webview-apk/` یک بیلدر پایتونی است که از همین `index.html` یک APK/AAB فول‌اسکرین و آفلاین می‌سازد.
راهنمای کامل: [`webview-apk/GUIDE-fa.md`](webview-apk/GUIDE-fa.md)

```bash
cd webview-apk
python3 build_apk.py doctor
python3 build_apk.py build --debug
```
